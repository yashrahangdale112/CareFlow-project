STEP 1 — Setup (Python + VS Code + Folder)

Time: ~10 minutes · Skill needed: none · Kuch bhi pehle se install nahi hona chahiye

Is step ka goal: aapke computer par Python chalne lage, VS Code khul jaye, aur CareFlow folder VS Code me open ho jaye. Bas.

1.1 Python install karna

A. Windows par

  1. Browser kholiye aur jaaiye: https://www.python.org/downloads/
  2. Page par bada yellow button dikhega — “Download Python 3.x.x” (jo latest stable version hai, 3.12 ya 3.13). Us par click kijiye. .exe file download hogi (jaise python-3.13.x-amd64.exe).
  3. Downloaded file par double-click kijiye.
  4. SABSE ZAROORI: installer ke pehle page par neeche do checkbox honge. “Add python.exe to PATH” wale ko zaroor tick kijiye. Yeh bhool gaye to baad me python command nahi chalega.
  5. Install Now par click kijiye aur finish hone tak wait kijiye.

B. Mac par

  1. Jaaiye https://www.python.org/downloads/ se .pkg installer download kijiye, ya
  2. Terminal kholiye (Command + Space → “Terminal” → Enter) aur likhiye: 
    brew install python@3.12
    (Agar Homebrew nahi hai to pehle https://brew.sh se install kar lijiye.)

C. Linux (Ubuntu) par

sudo apt update
sudo apt install -y python3 python3-pip python3-venv

D. Python install hua ya nahi — ye check kijiye

Terminal / Command Prompt kholiye aur ye 2 commands chala dijiye:

python --version
pip --version

Aisi output aani chahiye:

Python 3.12.7
pip 24.2 from /usr/lib/python3/dist-packages/pip (python 3.12)
Agar python kaam na kare to Windows par py --version try kijiye. Agar 'python' is not recognized aaye to Python dobara install kijiye aur “Add to PATH” wala checkbox tick kijiye.

1.2 VS Code install karna

  1. Jaaiye https://code.visualstudio.com/
  2. Bada blue Download button — apna OS khud detect ho jaata hai. Click kijiye.
  3. Installer chalaiye, Next → Next → Install.
  4. VS Code kholiye, left side me Extensions icon (chaar chhote boxes) par click kijiye.
  5. Search kijiye Python (Microsoft wala, blue icon) → Install.
  6. Usi tarah search karke install kijiye: Pylance, Jupyter (optional), Rainbow CSV (CSV file rangeen dikhegi — bahut helpful).

1.3 Project folder ready karna

  1. CareFlow_Project.zip file ko extract kijiye (right-click → Extract All).
  2. Ek CareFlow folder milega. Use is jagah move kar dijiye:
    • Windows: C:\Projects\CareFlow
    • Mac/Linux: ~/Projects/CareFlow
Path me space, Hindi characters ya bahut lamba naam mat rakhiye. C:\Users\Yash\Desktop\New folder (2)\CareFlow — aise path se problems aati hain.

1.4 Folder VS Code me kholna

  1. VS Code kholiye.
  2. Menu: File → Open Folder… (Mac par File → Open…)
  3. CareFlow folder select kijiye → Open.
  4. Left side Explorer me src, data, dashboard, outputs, docs, run_all.py dikhne chahiye.

1.5 VS Code ka terminal kholna

  1. Menu: Terminal → New Terminal (shortcut: Ctrl + `)
  2. Neeche ek panel khulega. Uski prompt line kuch aisi hogi:
C:\Projects\CareFlow>

Yaani aap sahi folder ke andar hain. Isi terminal me aage saare commands chalenge.

Terminal me folder badalna agar prompt galat folder dikhaye:
cd C:\Projects\CareFlow  (Windows)
cd ~/Projects/CareFlow  (Mac / Linux)
