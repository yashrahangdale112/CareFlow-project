STEP 2 — Dependencies Install Karna

Time: ~10 minutes · Internet required · Is step ka output: saare Python libraries install

Sabse pehle samajh lo: virtual environment (venv) ek alag “dabba” hai jisme sirf is project ki libraries install hoti hain. Isse aapke computer ki baaki Python settings kharab nahi hoti. Har baar project kholne par is dabbe ko activate karna padta hai.

2.1 Virtual environment banana

VS Code ka terminal kholiye (CareFlow folder me) aur ye chala dijiye:

Windows par

python -m venv .venv

Mac / Linux par

python3 -m venv .venv

Kuch seconds lagenge. Ab left panel me ek naya hidden folder .venv dikhega — yeh aapka “dabba” hai. Ise delete mat kijiye.

2.2 Virtual environment activate karna

Windows — PowerShell

.\.venv\Scripts\Activate.ps1

Agar error aaye: “running scripts is disabled on this system”, to pehle ye chala dijiye:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Windows — Command Prompt (CMD)

.venv\Scripts\activate.bat

Mac / Linux

source .venv/bin/activate

Activate hua ya nahi — pehchan

Terminal prompt ke aage (.venv) likha dikhne lagega:

(.venv) C:\Projects\CareFlow>
Yeh (.venv) dikhna zaroori hai. Nah dikhe to aap system Python me install kar rahe ho aur baad me “module not found” errors aayenge.

2.3 Core libraries install karna

pip install --upgrade pip
pip install -r requirements.txt

Yeh command requirements.txt me likhi libraries install karegi. Isme kya-kya hai:

Install hone me 1–3 minute lagte hain. Sab ke last me aisa dikhna chahiye:

pandas-2.x plotly-5.x scikit-learn-1.x seaborn-0.x streamlit-1.x ...

2.4 Install check karna

python -c "import pandas, numpy, sklearn, networkx, seaborn, plotly, streamlit, joblib, yaml, matplotlib; print('ALL CORE LIBRARIES OK')"

Output aana chahiye:

ALL CORE LIBRARIES OK
Agar koi library missing dikhe, to sirf wahi install kijiye, jaise:
pip install seaborn   ya   pip install joblib plotly

2.5 OPTIONAL: pm4py install karna (recommended)

pm4py duniya ki sabse badi open-source process mining library hai. Isse aapko official algorithms milte hain: Inductive Miner, Heuristics Miner, Alpha Miner aur Petri net export.

Zaroori baat: CareFlow pm4py ke bina bhi poora chalta hai. src/discover_models.py ke andar ek pure pandas + networkx discovery engine already likha hua hai. pm4py install karenge to result me extra Petri-net model bhi banega — report me “official algorithm” likhne ka bonus milta hai. 
pip install -r requirements-optional.txt

Ya directly:

pip install pm4py graphviz

Graphviz binaries (petri net image ke liye zaroori)

OSKya karna hai
Windowshttps://graphviz.org/download/ se 64-bit EXE installer download karke install kijiye.
Windows (PATH)Install ke baad: Start → “Environment Variables” → Path → Edit → New → C:\Program Files\Graphviz\bin → OK. Terminal band karke dobara kholiye.
Macbrew install graphviz
Ubuntusudo apt-get install -y graphviz

pm4py aur graphviz check karna

python -c "import pm4py; print('pm4py', pm4py.__version__)"
dot -V
pm4py 2.7.x
dot - graphviz version 11.0.0
Agar import pm4py fail ho jaye to koi tension nahi — python src/discover_models.py chalega aur log me likhega pm4py not installed - using the built-in pandas/networkx engine. Project pura complete rahega.

2.6 Streamlit check karna

streamlit hello

Browser khulega http://localhost:8501 par, ek demo page dikhega. Terminal me Ctrl + C daba kar band kijiye. Streamlit sahi hai.
