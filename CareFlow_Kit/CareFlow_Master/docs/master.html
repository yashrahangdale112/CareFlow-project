CareFlow kya hai? (1 minute me samjho)

Hospital me patient ka safar kai steps se guzarta hai — Registration → Triage → Lab Test → Diagnosis → Treatment → Discharge. Har patient ka yeh rasta thoda different hota hai: kuch patients ka test dobara hota hai, kuch ko ICU jana padta hai, kuch bahut zyada wait karte hain.

CareFlow ek hospital ke event log ko padhta hai (1 row = 1 patient ka 1 step) aur process mining lagakar ye nikalta hai:

  1. Discovery — asli pathway ka process model (Directly-Follows Graph) banata hai
  2. Analytics — bottleneck, waiting time, cost aur resource load nikalti hai
  3. Conformance — real cases expected pathway se kitne hatt gaye, woh check karti hai
  4. Prediction — kaunsa patient long stay (> 24 hours) hoga, woh predict karti hai
  5. Dashboard — sab kuch interactive Streamlit dashboard me dikhati hai
Aapka assignment letter kehta hai: submit karna hai Source Code · Project Documentation · Project Report · Presentation (PPT) · Model Evaluation Results · Final Demonstration. Yeh guide wahi 6 cheezein aapke liye bana deti hai — sab ready hai, bas run karke apne naam se submit kar dijiye.
