5. Database connect (MySQL / PostgreSQL)

Star schema: dim_patient, dim_activity, dim_department, dim_resource, dim_date + fact_case, fact_event. Files isi order me chalao: schema → load_data → kpi_queries → views.

# MySQL
mysql -u root -p < sql/schema.sql
mysql -u root -p --local-infile=1 careflow < sql/load_data.sql
mysql -u root -p careflow < sql/kpi_queries.sql

# Python (SQLAlchemy) — ek hi code, teen DB
python src/connect_db.py --engine sqlite
python src/connect_db.py --engine mysql
python src/connect_db.py --engine postgres
export CAREFLOW_DB_URL="mysql+pymysql://user:pass@localhost:3306/careflow"

Zaroori: MySQL me TIMESTAMP reserved word hai isliye column event_timestamp rakha gaya. event_index ko ROW_NUMBER() OVER (PARTITION BY case_id ORDER BY event_timestamp) se banao — yehi case ke andar event ka order hai, jo process mining ke liye must hai.

9. Common error aur fix

  • No module named pm4py → optional hai, fallback engine chalta rehta hai; real miners ke liye pip install -r requirements-optional.txt + Graphviz binaries
  • MySQL "Access denied" → LOAD DATA LOCAL INFILE ke liye --local-infile=1
  • Streamlit blank page → project root se chalao, paths relative hain
  • Timestamp text ban jaye → pd.read_csv(..., parse_dates=['timestamp'])
  • Inductive miner image error → sudo apt-get install -y graphviz (Windows: PATH me add karo)
